# Supabase DB 준비

현재 앱은 브라우저 저장 방식입니다. 이 폴더는 계획서의 DB 연결 단계 준비이며, 로그인과 실제 공지 저장 연동까지 완료된 상태는 아닙니다.

## 최초 설정

1. Supabase에서 해당 프로젝트를 열고 SQL Editor에서 새 쿼리를 만듭니다.
2. `schema.sql` 전체 내용을 넣고 Run을 누릅니다. 새 프로젝트에서 한 번만 실행합니다. 같은 이름의 테이블이 이미 있으면 삭제하지 말고 구조부터 비교하세요.
3. 프로젝트 루트의 `setup.html`을 열고 연결 확인을 누릅니다.

공개 URL과 Publishable key는 `supabase-config.js`에 설정되어 있습니다. Secret key, service_role 키, DB 비밀번호는 클라이언트 코드에 넣지 않습니다.

## 접근 권한

- 계정 생성 시 기본 역할은 학생입니다. 교사 역할은 프로젝트 관리자만 지정합니다.
- 교사는 본인 그룹과 공지를 관리하고 학생을 그룹에 등록합니다.
- 학생은 가입한 그룹의 공지와 로그인 사용자 대상 전체 공지를 읽습니다.
- 개인 일정과 공지 완료 상태는 본인만 읽고 수정합니다.
- 연결 확인 함수는 설정 버전만 반환하며 사용자 데이터를 노출하지 않습니다. 성공 응답이 모든 접근 권한 검증을 대신하지는 않습니다.

## 다음 단계

계정 로그인 연결, 교사 공지 저장, 학생 공지 조회, 완료 표시와 일정 저장 순서로 연결합니다. 실제 학생/교사 계정을 나누어 권한을 검증한 뒤 사용합니다. 댓글 및 서버 파일 첨부는 후속 단계입니다.
