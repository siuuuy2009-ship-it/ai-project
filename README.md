# 학교 플래너

학교 공지, 과제 마감일, 개인 일정을 한곳에서 확인하는 웹앱입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 별도 설치나 빌드가 필요하지 않습니다.

## 현재 구현

- 학생: 대상 그룹에 맞는 공지·과제 확인, 검색·필터, 마감일순 정렬, 완료 체크, 플래너 저장
- 플래너: 월간 달력, 과제 일정, 개인 일정 추가·삭제
- 선생님: 학급·동아리 그룹 만들기, 공지·과제 등록·수정·삭제, 작은 첨부파일 등록
- Supabase 로그인 후 공지, 완료 상태, 개인 일정 및 플래너 수정값을 DB에 저장합니다.

기존 DB에는 `supabase/upgrade-v2.sql` 적용이 필요합니다. 신규 DB는 `supabase/schema.sql` 다음에 해당 업데이트를 실행합니다. 적용과 계정별 검증 방법은 `docs/cloud-setup.md`를 참고하세요.
