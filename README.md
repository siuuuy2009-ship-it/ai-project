# 학교 플래너

학교 공지, 과제 마감일, 개인 일정을 한곳에서 확인하는 프론트엔드 체험판입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 별도 설치나 빌드가 필요하지 않습니다.

## 현재 구현

- 학생: 대상 그룹에 맞는 공지·과제 확인, 검색·필터, 마감일순 정렬, 완료 체크, 플래너 저장
- 플래너: 월간 달력, 과제 일정, 개인 일정 추가·삭제
- 선생님: 학급·동아리 그룹 만들기, 공지·과제 등록·수정·삭제, 작은 첨부파일 등록
- 데이터는 브라우저의 로컬 저장소에만 저장됩니다. 첫 방문에는 예시 데이터가 표시됩니다.

실제 로그인, 여러 사용자 간 데이터 공유, 서버에 첨부파일 저장은 Supabase 연동 단계에서 구현할 예정입니다.
